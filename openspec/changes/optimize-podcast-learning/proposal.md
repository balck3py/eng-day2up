# Proposal

## Why

播客阅读学习需要减少选词翻译前的网络往返，并允许从不熟悉的词开始重听，避免每次都回到整条字幕开头。设备直连翻译的数次优化已经上线，需要补齐规格和完成记录；Daily News 新增逐词 SRT 后，可以在保持逐条双语阅读的同时扩展更精确的起播位置。

## What Changes

- **补记已上线优化**：设置可选择 Vercel 或设备发起模型请求；自定义本地模型继续优先。设备模式的单词始终直接请求 AI，跳过网站词库，句段翻译保留流式显示。
- **补记最终配置行为**：首次经登录和准入校验取得网站模型配置后，保存在当前浏览器并跨刷新复用；取消逐次配额授权和五分钟过期重新获取。提供手动重新获取，退出登录、切换账户或关闭设备模式清除配置；关闭开关时保留原 Vercel 流程。
- **待实现三轨识别**：分别识别英文句级、中文句级和英文逐词 SRT，避免将同为英文且带 `rel="captions"` 的逐词轨误作主字幕。仅使用 feed 声明的实际 URL。
- **待实现词级定位**：详情仍按英文句级条目展示并匹配中文；逐词轨只提供正文词与原音频位置的映射。普通轻点英文词从该词起播，重复点同词重播，不改变所选单句/连续模式。
- **已确认播放边界**：完整可靠对齐的句子以首词到末词的实际时间作为整句播放范围；点词使用所点词起点。单句模式均在该句最后一个词结束时暂停，连续模式继续后文；无可靠逐词数据的句子沿用原句级边界，不增加固定 0.5 秒补偿。
- **保留阅读交互**：长按、拖选和键盘选区继续自动翻译；点中文、时间或非词区域仍可整句点播；顶部四行翻译浮窗、底部默认折叠控制区和 0.1× 步长倍速保持。
- **兼容旧剧集**：没有逐词轨、资源加载失败或某句不能可靠对齐时，保留该句原有点播，不用均分时长猜词时间，不将后续词错贴到其他句。
- 将上述内容作为同一个 feature 优化管理：已上线任务据实勾选，逐词播放及其验收保持未完成；本次只补规划，不实现、不归档、不发布业务代码。

## Capabilities

### New Capabilities

- `device-origin-translation`：设备模型请求选择、授权配置获取、本地配置复用、直接 AI 查词、无逐次网站配额检查、失败与兼容规则；对应已经上线的最终行为。
- `podcast-word-seeking`：逐词 SRT 与句级正文对齐、轻点词起播、可靠降级和词级操作可达性；对应本次待实现能力。

### Modified Capabilities

- `podcast-catalog`：将字幕资源识别与独立降级扩展为句级英文、句级中文和可选逐词英文三轨。
- `podcast-transcript-playback`：将单句、连续、暂停恢复、当前条目标识和双语点播规则扩展为支持句内词起点，保留原句级展示与文本选择行为。
- `podcast-player-controls`：明确倍速下比较所选播放段的实际媒体时间；有逐词数据时使用末词终点，无逐词数据时保留句级终点。

## Impact

- 已上线范围：`src/lib/translate/{deviceTranslation,client,localModel}.ts`、`src/lib/dict/clientLookup.ts`、配置 GET 接口、设置开关、初始化与登出清理、难词释义和选择浮窗；补记对应单元/接口/浏览器测试与部署提交证据。
- 待实现范围：`src/lib/podcast/{feed,load,srt,types,player,gesture}.ts`、`PodcastDetail.tsx`、按节目/剧集获取逐词轨的可选接口及播客测试；优先增加纯对齐模块，保持现有选区提取可跨文本 span 工作。
- 保留四节目导航、节目内资源范围与安全限制、既有路由和剧集 ID；其余节目/旧剧集没有逐词轨时正常降级。无数据库迁移，无新增模型、转录服务或第三方依赖。
- 当前主规格没有设备直连能力，本次新增对应规格；服务端 `translation-scheduling` 仍只约束 Vercel 路径，不把设备模式重新纳入网站配额。
