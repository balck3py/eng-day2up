# 播客与选中即翻译

在顶部导航的「单词本」后打开第四个入口「播客」，先选择四个节目之一，再按日期从新到旧浏览剧集；图片、标题、日期和卡片留白都可以点击进入详情。点击「刷新」重新获取目录。详情地址可以直接打开或刷新。

节目首页的四张卡片只显示封面，点击封面选节目；节目名称保留为链接的可访问名称。

初始为单句模式：点击一条英文或中文，从对应英文时间段起点播放，句末暂停；再次点击重播。选择「连续」或点击「从头播放」可连续收听；连续模式暂停后点任一句会从该句恢复连续播放，随后继续后面的内容。通过模式选择器切回单句。离开详情停止音频，返回后不自动播放。

英文是主时间轴，中文按相同起止时间配对并展示在英文下方。「显示中文」默认开启，显隐不影响音频。旧节目没有中文仍可以使用；中文字幕加载失败可重试，未配对的条目只展示英文。

播客详情和「加载第三方网站」阅读页支持选中即翻译。长按、拖选或用键盘选择英文，停下约 250ms 后自动在视口顶部显示紧凑浮窗。单词显示中文释义、音标、发音和生词本按钮，收藏时保存所在英文句子；短语、句子或段落只显示中文译文。最多处理 2000 字，收藏上下文最多 500 字。

浮窗内容区最多显示 4 行，超出后内部滚动。内部点击、复制、收藏、发音和内部滚动保留浮窗，滚动正文关闭；也可按 Escape 或点击关闭。关闭不改变播客状态；重新主动选择可再次查询。长按选区不会点播字幕。

## 底部播放控制区与倍速

详情页底部控制区默认折叠，只留一个展开箭头；点击后显示模式、播放/暂停、从头播放、时间、中文开关和速度。刷新或进入其他剧集也默认折叠，点字幕播放不会自动展开。点右上角箭头折叠后只留一个展开箭头；折叠或正文滚动不会暂停播放，展开时保留原模式、速度和中文状态。正文底部预留阅读空间，最后一句仍可滚到控件上方。

速度滑杆范围 0.5–1.2×，步长 0.05×，首次为 1.00×。播放中即时生效，暂停时调整不会开始播放；重置恢复 1.00×。速度在当前浏览器记住，换集或刷新沿用；存储不可用/坏值回退 1.00×。重复点句、从头播放和音频重试保留速度。字幕时间不随速度缩放，不添加额外 0.5 秒尾部补偿。

## 数据和运行

固定节目为 Daily News 10 Mins（daily-news）、AI Digest（ai-digest）、Talk Today（topic）和 How It Works（deep-dive），feed 均位于 `https://qiniu.aiquannei.com/podcast/<节目目录>/feed.xml`。只读取当前节目声明的同源同目录资源，不猜测中文文件名。MP3 直接播放，应用接口仅代理目录和字幕文本，沿用登录和账号准入。目录请求使用 no-store、重新验证和受控刷新参数；发布方仍应在每天更新时刷新 CDN 或降低 feed 缓存时间（当前源声明一年）。

Next.js 16.3.0 的本地指南已核对：动态 params 需 await；交互和媒体只在客户端组件；GET 接口默认动态，仍明确使用 no-store，避免浏览器及上游缓存目录。

### 页面与接口兼容

- `/podcast`：四节目入口；`/podcast/shows/<programId>`：该节目剧集；`/podcast/shows/<programId>/<episodeId>`：详情。
- 旧 `/podcast/<episodeId>` 跳转到 Daily News 对应新详情，不改变旧 ID。
- 新 GET `/api/podcast/shows/<programId>` 返回 `{ episodes }`，新 GET `/api/podcast/shows/<programId>/<episodeId>` 返回该期信息、配对字幕和各语言错误；节目 ID 必须在注册表内。
- 旧 `/api/podcast` 和 `/api/podcast/<episodeId>` 保留 Daily News 行为与响应结构；所有接口沿用登录与准入。
- 复核 Next 16.3 本地指南：新路由 params 用 await，客户端操作媒体，GET 与上游请求明确 no-store。

### 静态资源缓存

- 首页和剧集封面使用 `next/image`，按实际尺寸输出压缩图，避免直接加载四张合计约 4MB 的原图。图片缓存最短七天，与源站缓存时长取较大值；目前四张封面源站均返回一年 `max-age`。
- 配置统一在 `next.config.ts`：Vercel 使用内置图片优化缓存，本地 `next start` 使用 `.next/cache/images`，浏览器可按响应头复用优化图。无需另外添加 `vercel.json`。[Vercel 官方说明](https://vercel.com/docs/image-optimization)。
- Next 生成的带内容哈希 JS/CSS/字体保持框架的一年 `immutable`；根目录 public 图片/图标/字体设置浏览器一天、共享 CDN 三十天缓存。替换无哈希静态文件或源站同名封面时，需更新文件名或 URL 版本参数。
- feed/字幕接口保持原刷新策略，避免缓存修正前的字幕；音频直接遵循源站缓存策略，不预先下载整期音频。
- `next dev` 的缓存行为不同，需用 `npm run build` + `npm start` 验证实际生产头；浏览器开启“禁用缓存”或强制刷新时仍会重新请求。

## 验证

- `npm test`：离线单元/接口回归，不请求真实服务。
- `PODCAST_LIVE_TEST=1 npm test -- src/lib/podcast/live.test.ts`：真实 feed 更新请求、双语配对和 MP3 Range 检查。
- `npx playwright install chromium webkit`，然后 `npx playwright test --config playwright.podcast.config.ts`：隔离的本地鉴权服务与夹具，不使用真实 Supabase 账号，不执行清空生词本操作。
- `npm run build`：需提供项目正常的 NEXT_PUBLIC_SUPABASE_URL / NEXT_PUBLIC_SUPABASE_ANON_KEY 配置；构建不需要真实账号。

单句按原 SRT 的时间段控制，正常前台播放目标为终点后最多 150ms 暂停；后台时单句主动暂停以避免浏览器节流越过下一句。原始字幕与说话边界的误差无法由播放器自动修正。WebKit 移动模拟不能替代真实 iPhone 上的长按菜单与音频听感验收。
