# 复习模式：新增「中译英」题型 设计文档

日期：2026-08-18
状态：已确认，待编写实施计划

---

## 1. 目标

复习页当前只有一种题型：正面出英文单词，翻面看中文释义，手动标记「认识 / 不认识」。

本次新增第二种题型——**中译英**：正面出中文释义，用户输入英文单词，系统判定对错。两种题型在同一轮复习中按用户设定的比例穿插出现。

### 1.1 非目标

- 不改动 `familiarity` 的计算规则（仍是 ±1，封顶 5 / 兜底 0）
- 不引入间隔重复调度（`due_at` / `ease_factor` / `interval_days` 继续不动）
- 不做「中译英」的语音输入或手写输入
- 比例设置不持久化（与现有的「顺序/随机」模式保持一致，均不写 localStorage）
- 不改动 `/api/review/mark` 接口

## 2. 出题混合

### 2.1 比例滑杆

设置页在「顺序 / 随机」单选组下方新增一条滑杆：

- 左端标 `英译中`，右端标 `中译英`
- `<input type="range" min="0" max="100" step="10">`，默认值 `50`
- 值的语义：**中译英题目所占百分比**。`0` = 全部英译中，`100` = 全部中译英
- 滑杆下方实时显示 `英译中 50% · 中译英 50%`

### 2.2 队列生成

点击「开始」时两步走：

1. `orderCards(all, mode, seed)` —— 现有排序逻辑，完全不动
2. 新函数按比例给每张卡随机分配题型

分配使用确定性 PRNG，同一种子产出可复现，便于单测。为此把 `src/lib/review/order.ts` 中私有的 `prng` 抽到 `src/lib/review/prng.ts`，由 `order.ts` 与新模块共同导入。`order.ts` 的对外行为不变。

新模块 `src/lib/review/quiz.ts`：

```ts
export type QuizType = 'en2cn' | 'cn2en'

export interface ReviewCard<T> {
  item: T
  type: QuizType
}

/**
 * 按 cnRatio（0-100，中译英占比）给每张卡分配题型。
 * 被分到 cn2en 但 canAskCn 返回 false 的卡，从队列中剔除。
 */
export function assignQuizTypes<T>(
  items: T[],
  cnRatio: number,
  canAskCn: (item: T) => boolean,
  seed: number,
): ReviewCard<T>[]
```

### 2.3 无中文释义的词

`senses` 为空的词无法作为中译英题面（题面即是释义）。处理规则：

**只有当该词被抽中「中译英」时才从本轮队列剔除。**

这样滑杆拉到最左（`cnRatio = 0`）时一个词都不会丢，语义上更合理；拉到最右时所有无释义词被跳过。

副作用是实际交付的比例会偏离设定值——这是可接受的，但数量差异必须对用户可见。开始复习后在进度行下方提示一行：

```
本轮 8 个 · 2 个无中文释义已跳过
```

跳过数为 0 时不显示该提示。

## 3. 中译英卡片

### 3.1 题面

**只显示中文释义列表**（沿用英译中背面的释义渲染：词性 + 释义，多条并列）。

明确不显示：

| 字段 | 原因 |
|---|---|
| `word` | 即答案 |
| `phonetic` | 音标直接泄露拼写 |
| 发音按钮 | 同上 |
| `sourceContext` | 收藏时的原句通常直接包含该单词 |

释义下方是文本输入框 + 「提交」按钮。输入框在卡片挂载时自动聚焦。

### 3.2 判定规则

新模块 `src/lib/review/answer.ts`：

```ts
/** 宽松匹配：忽略大小写、首尾空格与首尾标点。空输入一律判错。 */
export function isAnswerCorrect(input: string, word: string): boolean
```

实现复用 `src/lib/text/normalize.ts` 的 `normalizeWord`——它已经做了「剥首尾非字母字符 + 转小写」，词内的撇号与连字符保留。判定即比较两者归一化后是否相等。

边界：`normalizeWord(input)` 为空串时直接判错，避免空输入与异常词条归一化后互相匹配。

**不接受**词形变化（复数、时态）与拼写误差——本题型的目的就是拼写训练。

### 3.3 提交后的行为

提交（点按钮或回车）后立即判定，并**自动写熟练度**：答对 → `known: true`，答错 → `known: false`，调用现有 `/api/review/mark`，与英译中一样不等待返回。

判定结果以文字明示：答对显示「答对」，答错显示「答错」。

同时展开完整背面（与英译中翻面后的内容是同一块组件）：正确答案、音标、发音按钮、释义、例句、熟练度。

答错时在正确答案旁额外以红色显示用户输入的内容，便于对照。

判定后**不自动跳到下一张**，需点击「下一个」或按回车才继续——答错时要给用户看清正确答案的时间。

## 4. 键盘交互

现有实现是全局 `keydown`：空格翻面、翻面后 `1` = 不认识 / `2` = 认识。

中译英卡片上输入框处于聚焦状态，空格必须能正常输入空格，因此：

- **全局 `keydown` 处理器只在当前卡片为 `en2cn` 时挂载**
- 中译英卡片自己处理回车：未提交时 = 提交，已提交时 = 下一个

## 5. 文件组织

`src/app/review/page.tsx` 现为 230 行，直接加会到 400+ 行。拆分如下（沿用 `src/components/` 的扁平命名惯例）：

| 文件 | 职责 |
|---|---|
| `src/components/ReviewCardBack.tsx` | 音标 / 发音按钮 / 释义 / 例句 / 熟练度，两种题型共用 |
| `src/components/ReviewFlipCard.tsx` | 英译中卡片，现有翻面逻辑平移 |
| `src/components/ReviewInputCard.tsx` | 中译英卡片，输入 + 判定 + 展开 |
| `src/app/review/page.tsx` | 设置页、队列调度、计数、标记提交 |

组件间通过明确的 props 通信，卡片组件不直接调用接口——标记统一由 `page.tsx` 的 `mark(known)` 回调发出，保持提交路径只有一条。

`data-testid="review-word"` 保留在英译中卡片的单词上（现有 e2e 依赖它）；中译英卡片提交后展开的正确答案使用新的 `data-testid="review-answer"`。

无数据库变更，无接口变更。中译英复用 `POST /api/review/mark`（`{ id, known }`）。

## 7. 测试

### 7.1 单元测试（vitest）

`src/lib/review/answer.test.ts`：

- 完全一致判对
- 大小写差异判对（`Serendipity` vs `serendipity`）
- 首尾空格判对
- 首尾标点判对（`serendipity.`）
- 词内连字符须保留（`well-being` vs `wellbeing` 判错）
- 空输入判错
- 纯空格输入判错
- 拼写错误判错（`serendipty`）

`src/lib/review/quiz.test.ts`：

- `cnRatio = 0` 时全部为 `en2cn`，且无释义词一个不丢
- `cnRatio = 100` 时全部为 `cn2en`，且无释义词全部被剔除
- `cnRatio = 50` 时两种题型都出现
- 同一种子产出相同结果
- 不同种子产出不同结果
- 不修改入参数组
- 空数组返回空数组

`src/lib/review/order.test.ts` 保持不变——`prng` 抽取属于内部重构，对外行为不变，现有测试全绿即是证明。

### 7.2 端到端测试（playwright）

现有两个用例会因默认 50% 比例而失败（`alpha` / `beta` / `gamma` 等测试词大概率无中文释义，会被跳过一部分，断言数量对不上）：

- `复习流程走完一轮并更新熟练度`
- `随机模式打乱顺序`

两者均需在点击「开始」前先把滑杆拖到最左（`cnRatio = 0`，纯英译中），其余断言不变。

新增用例 `中译英题型判定答案`：铺一个词库中确有中文释义的词（用 `serendipity`——该文件其余用例已在用它，实施前需先确认它在 Supabase 词库中 `senses` 非空，若为空则另选一个已确认的词）→ 滑杆拖到最右 → 开始 → 输入正确英文 → 断言出现「答对」与正确答案；再走一轮输入错误拼写 → 断言出现「答错」且红色显示用户输入。

滑杆是 `<input type="range">`，Playwright 用 `fill('0')` / `fill('100')` 直接赋值即可，无需模拟拖拽。

## 8. 验收标准

1. 设置页可拖动比例滑杆，两端与中点均可选，实时显示百分比
2. 滑杆最左时全程英译中，行为与改动前完全一致
3. 滑杆最右时全程中译英，无中文释义的词被跳过并显示跳过提示
4. 中译英题面不出现英文单词、音标、发音按钮与例句
5. 输入正确（含大小写 / 首尾空格 / 首尾标点差异）判对并 `familiarity + 1`
6. 输入错误判错并 `familiarity - 1`，同时显示正确答案与用户输入
7. 英译中卡片上空格翻面、`1` / `2` 标记照常工作
8. 中译英卡片上空格可正常输入，回车提交，再回车进入下一张
9. `npm run test` 与 `npm run test:e2e` 全绿
