# 云端翻译请求位置

在「设置 → 云端翻译请求位置」切换：关闭时沿用 Vercel 翻译链路，开启时由当前设备的浏览器直连网站预设的 OpenAI 兼容模型。默认关闭。选择只保存在当前浏览器，刷新后沿用，其他同源标签页同步更新。

已有的自定义本地模型继续优先使用。新开关不改写或清除自定义 Base URL、模型、Key 和提示词；清除自定义模型后，才按此开关选择预设云端模型的请求位置。

设备模式启用后，打开页面会预取 Vercel 上的 `CLOUD_BASE_URL`、`CLOUD_MODEL`、`CLOUD_API_KEY` 和关闭思考开关。预取不调用模型、不扣配额；同一页面的并发读取复用一次请求，配置只在内存中复用五分钟，不写 localStorage、sessionStorage 或浏览器 HTTP 缓存。刷新后重新获取，退出登录、切换账户或切回 Vercel 会清除配置；过时响应不能恢复已清除的配置。

真正调用模型前，仍向网站验证登录/准入并扣除每日配额；这次授权请求不携带所选文本、不转发模型请求。之后浏览器直接向模型的 `/chat/completions` 发起请求。段落译文保留流式显示，单词仍先查网站词库，只有 AI 补全或上下文释义需要模型请求。关闭开关后，原有服务端调度、对冲、兜底和配额流程保持原样。

## 配置接口

- `GET /api/translate/config`：仅对已登录且符合 `ALLOWED_EMAILS` 的账户返回四个模型配置字段；缺少模型配置或不是有效 HTTPS 端点时返回 503。
- `POST /api/translate/config`：登录与配额授权，成功返回 `{ ok: true }`，超额返回 429。它不请求模型。
- 两个方法均拒绝外部 Origin，响应设置 `private, no-store, max-age=0`、`Vary: Cookie` 和 `Cross-Origin-Resource-Policy: same-origin`，不开放跨域读取配置。

API Key 进入浏览器后，已授权用户可通过开发者工具查看它。站内配额限制正常应用流程，无法限制持有 Key 的人绕过网站直接调用模型；此模式面向现有受信任账户。Key 不会写入设置表单，也不会打包进公开 JS。

## 连接失败与验证边界

模型端点必须允许本站来源的 CORS 请求以及 `Authorization`、`Content-Type` 请求头。失败时明确提示，用户可切回 Vercel；不悄悄把失败的设备请求改由 Vercel 发送。2026-11-03 对 [AIPing 文档中的标准端点](https://aiping.cn/docs/API/text-models) 发起了本站 Origin 的 OPTIONS 预检，返回 204，并允许所需方法和头；实际生产 Base URL 仍以网站配置为准。

直连改变的是网络路径，能否更快取决于用户设备与模型服务之间的网络和模型排队情况，不保证必然提速。当前未使用真实用户账号或供应商 Key 进行实际翻译测速。
