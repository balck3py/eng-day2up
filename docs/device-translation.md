# 云端翻译请求位置

在「设置 → 云端翻译请求位置」切换：关闭时沿用 Vercel 翻译链路，开启时由当前设备的浏览器直连网站预设的 OpenAI 兼容模型。默认关闭。选择只保存在当前浏览器，刷新后沿用，其他同源标签页同步更新。

已有的自定义本地模型继续优先使用。新开关不改写或清除自定义 Base URL、模型、Key 和提示词；清除自定义模型后，才按此开关选择预设云端模型的请求位置。

设备模式启用且本地没有有效配置时，页面会获取 Vercel 上的 `CLOUD_BASE_URL`、`CLOUD_MODEL`、`CLOUD_API_KEY` 和关闭思考开关。同一页面的并发读取复用一次请求，配置保存在当前浏览器的 localStorage（`deviceTranslationConfig`），刷新页面、重新打开网页或后续翻译均直接复用，不设五分钟有效期，不自动定时获取。浏览器禁止本地存储时退回页面内存复用。

设备模式不再发起逐次登录/配额检查，不消耗网站每日配额；单词翻译、句段翻译和难词上下文释义直接向模型的 `/chat/completions` 请求。段落译文保留流式显示。单词不调用 `/api/word`，不回查纠正后的词，不自动写回网站词库；释义和音标均来自本次 AI 结果，发音和收藏按钮保留。自定义模型仍优先，也跳过词库。收藏状态查询、发音等原有辅助功能仍可独立请求网站。关闭开关后，原有词库查询、自定义模型兜底、服务端调度、对冲和配额流程保持原样。

退出登录、切换账户或切回 Vercel 会清除设备模型配置；清除和更新会让其他已打开标签页中的旧配置失效，过时响应不能恢复已清除的配置。网站更换模型、地址或 Key 后，在设置点击「重新获取配置」即可主动更新。模型请求失败时只提示错误，不自动回源获取配置或改用 Vercel。

## 配置接口

- `GET /api/translate/config`：仅对已登录且符合 `ALLOWED_EMAILS` 的账户返回四个模型配置字段；缺少模型配置或不是有效 HTTPS 端点时返回 503。
- 已删除 `POST /api/translate/config` 的逐次授权接口，不再调用站内配额逻辑。
- GET 拒绝外部 Origin，响应设置 `private, no-store, max-age=0`、`Vary: Cookie` 和 `Cross-Origin-Resource-Policy: same-origin`，不开放跨域读取配置；HTTP 缓存仍禁用，本地持久化由应用负责。

API Key 与模型配置一起保存在当前浏览器，可通过开发者工具查看。首次获取配置仍要求登录和准入授权，之后设备请求不经过网站配额检查，上游自己的限额和计费照常；此模式面向现有受信任账户。Key 不会写入设置表单，也不会打包进公开 JS。

## 连接失败与验证边界

模型端点必须允许本站来源的 CORS 请求以及 `Authorization`、`Content-Type` 请求头。失败时明确提示，用户可切回 Vercel；不悄悄把失败的设备请求改由 Vercel 发送。2026-11-03 对 [AIPing 文档中的标准端点](https://aiping.cn/docs/API/text-models) 发起了本站 Origin 的 OPTIONS 预检，返回 204，并允许所需方法和头；实际生产 Base URL 仍以网站配置为准。

直连改变的是网络路径，能否更快取决于用户设备与模型服务之间的网络和模型排队情况，不保证必然提速。当前未使用真实用户账号或供应商 Key 进行实际翻译测速。
